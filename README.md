# 🧠 Neural Network Practice

A collection of hands-on neural network notebooks where I work through foundational concepts in deep learning, documented as part of my broader research journey in computational genomics and drug repurposing for small cell lung cancer.

These notebooks follow the [StatQuest Illustrated Guide to Neural Networks and AI](https://statquest.org/) and are implemented in **Python** using **Google Colab**.

---

## 📂 Notebooks

| Notebook | Description |
|---|---|
| `neural_network_pretrained_weights.ipynb` | Building a simple neural network with pretrained weights and biases using PyTorch. Step-by-step visualization of how each neuron transforms input values through weights, biases, and ReLU activation. |

---

## 🔧 Tools & Libraries

- **PyTorch** — building and running the neural network
- **Matplotlib & Seaborn** — visualizing neuron outputs
- **Google Colab** — development environment
